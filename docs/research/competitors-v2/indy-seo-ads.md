# Competitor Set C: Indianapolis local SEO, Google Ads, web design shops

Researched Oct 9, 2026. Method: WebSearch for discovery, WebFetch on homepages plus a second page (FAQ/blog/pricing/city page) where one loaded. "Not published" means the firm's own site did not list it in what I could read. Many city "best of" lists are published by agencies that rank themselves first (Web Tonic, Xpand Digital); treat those as marketing, not neutral data.

## Patterns across the set
1. Almost nobody publishes a price. Exceptions: Exceedion (site ranges), Sharp Guys ($7,500), Ritner ($1,000/mo), Thrive ($500 hook), Web Tonic ($3,000/mo Ads).
2. "No long-term contract" is common copy (Collective Alternative, Sixth City, Thrive, Lewis, Proof, EZ). Nobody states a notice period, exit handoff, or what is delivered at exit.
3. Account ownership: only Web Tonic (Google Ads in client's name) and CodeWCG (templated) say it. Domain, hosting, GA4, GTM, GBP ownership: no Indy firm addressed.
4. Reporting promises are vague ("walk you through reports", "live dashboards"); nobody commits to a cadence, a named metric set, or a call.
5. Local pages: EverEffect has Indy+Westfield offices; Xpand names Carmel/Fishers/Greenwood/Plainfield; MAK and out-of-state shops run templated suburb pages. Few have genuine neighborhood or suburb depth.
6. Proof is mostly badges, years in business, and testimonials; few give numeric local results.
7. Web floor is about $7,000-$7,500 among the local studios found.

## Opportunities for CPC
1. Lead with published prices in Indy search results ($1,200/$2,400/$4,800, $900 site, $2,500, $750 logo); this alone separates CPC from nearly every competitor.
2. Make a plain "You own everything" page: Google Ads, GA4, GTM, GBP, domain, hosting, social logins in your name from day one, written into the agreement, with an exit checklist and handoff within a set number of days.
3. Own the "3-month minimum, then month to month" contract clarity; state notice period and what you hand over at exit (no one else does).
4. Undercut the $7,000+ local web floor with $900 and $2,500 tiers; add a comparison page "what a site costs in Indianapolis" using sourced ranges.
5. Build real suburb pages (Carmel, Fishers, Noblesville, Westfield, Zionsville, Greenwood, Plainfield, Brownsburg) with local specifics, not name-swapped templates (CodeWCG shows the template pattern is out there and thin).
6. Nonprofit lane: Ad Grants management at a reduced rate, local-specific; only Happy To Help (Fishers) appeared, and others cover nonprofits generically.
7. Commit to a reporting standard: monthly report, a call, defined metrics (calls, form fills, GBP actions, spend), shared dashboard in client-owned Looker/GA4.
8. Counter "agency bloat" with the 8-client cap and one named person; competitors list team sizes of 2-10 yet sell as large agencies.
9. Offer the $3,000 strategy engagement as the answer to Helium-style "build your capability" positioning, scaled to SMB, with half credited to retainer.
10. Publish a Google Ads fee page: flat fee vs % of spend, minimum spend, no setup fee; Indy rivals say nothing.
