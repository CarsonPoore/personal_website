# Research: design-motion

## Summary
Research across Awwwards-adjacent commentary, 2026 trend reality-checks, and browser-support sources confirms the existing CPC system (Figtree-only type with a clamp() scale to --step-6, navy/cobalt/amber tokens, IntersectionObserver reveals, split-word headlines, Remotion loops gated by viewport + reduced-motion) is already aligned with what reads premium in late 2026: oversized editorial display type instead of hero imagery, restrained state-communicating motion, token-driven consistency, and modular grid-break moments. The platform picture is favorable for plain CSS/JS: scroll-driven animations (animation-timeline: scroll()/view()) are cross-browser (Chrome 115+, Firefox 133+, Safari 18.2/18.4+), and cross-document View Transitions work in all engines (Chrome/Edge 126+, Safari 18+, Firefox 144, ~88% global support as of 2026) — meaning multi-page fades and element morphs need only a CSS opt-in plus @supports-guarded enhancement. What reads dated: scroll-jacking, full-viewport parallax heroes, heavy WebGL/Spline scenes, original glassmorphism, blob shapes, generic AI imagery, and kinetic type everywhere. The moves below extend the current system (new patterns reuse --step-*, --ease-out, .reveal, video.motion-loop) rather than replacing it.

## Actionable
- 1. SUPER-DISPLAY HERO UTILITY — add .display-xl { font-size: clamp(4.5rem, 3rem + 8vw, 11rem); line-height: 0.95; letter-spacing: -0.02em; font-weight: 800; } for one headline per new page (practice pages, audience pages). Optionally let one word bleed past the container (margin-inline: calc(var(--gutter) * -0.5); overflow-x: clip on the section). Pair with --step-0 eyebrow text in amber for the editorial big/small contrast. Do NOT animate letter-by-letter; reuse existing [data-split] word reveal.
- 2. CSS SCROLL-PROGRESS BAR UPGRADE — replace the JS scroll listener in motion.js with @supports (animation-timeline: scroll()) { .scroll-progress { animation: grow linear; animation-timeline: scroll(root); transform-origin: left; } } and keep the JS path as the @supports-else fallback. Compositor-driven, zero main-thread cost.
- 3. VIEW TRANSITIONS FOR THE WHOLE MPA — add to styles.css: @view-transition { navigation: auto; } ::view-transition-old(root), ::view-transition-new(root) { animation-duration: 240ms; } and give the header/nav view-transition-name: site-nav so it holds still while content cross-fades. Guard with @media (prefers-reduced-motion: no-preference). Supported Chrome/Edge 126+, Safari 18+, Firefox 144; older browsers just get instant navigation — pure progressive enhancement, ~10 lines, no JS.
- 4. NAMED-ELEMENT MORPHS ON KEY PATHS — give the four practice cards on the services index view-transition-name: practice-marketing|technical|strategy|coaching (unique per element) and the matching hero block on each practice page the same name: the card morphs into the page header on navigation. Only works where names match 1:1; set names via a data attribute + one CSS rule per page.
- 5. CSS-ONLY view() REVEAL TIER — for low-stakes elements (section rules, images, loop containers), add @supports (animation-timeline: view()) { .reveal-css { animation: rise-in both; animation-timeline: view(); animation-range: entry 0% entry 60%; } } inside @media (prefers-reduced-motion: no-preference). Keep the existing IO-based .reveal for one-shot staged content (scroll-TRIGGERED CSS is Chrome-145-only in 2026, not interop). Two tiers: progress-linked = CSS, fire-once = IO.
- 6. CLIENT/SECTOR TICKER — one marquee strip (sectors served or Indy neighborhoods/towns for the local pages: 'Broad Ripple · Carmel · Fountain Square · Greenwood…') in --step-1 Figtree 600 on navy. Implementation: track duplicated once, second copy aria-hidden="true", @keyframes { to { transform: translateX(-50%) } } linear 30-40s, animation-play-state: paused on :hover and :focus-within; under prefers-reduced-motion render as a static wrapped row (animation: none; flex-wrap: wrap). Max one per page.
- 7. STICKY RAIL ON LONG PAGES — practice and audience pages get a left rail (position: sticky; top: calc(var(--gutter) + 72px)) listing page sections; one IntersectionObserver with rootMargin: '-40% 0px -55%' toggles an .active class (cobalt text + 2px amber left bar, transition 200ms var(--ease-out)). Collapses below ~1024px into nothing (the page just reads linearly). Also the natural home for a five-step method mini-map on method-adjacent pages.
- 8. OVERSIZED AMBER NUMERALS AS STRUCTURE — number the five-step method and any process list with absolutely-positioned amber numerals at --step-6, weight 200-300 (thin weight keeps them architectural, not shouty), opacity ~0.35 on bone / 0.25 on navy, z-index behind the text card. Ties new pages to the existing amber-numeral convention with zero new tokens.
- 9. COUNT-UP IMPACT STATS — 3-up grid (8-client cap, 3-month minimum, years, projects) with real values in the HTML; small IO-triggered JS counts from 0 over ~1000ms with ease-out, fires once, skipped entirely under reduced motion (number is already in markup, so nothing breaks). Numerals in amber at --step-5, labels at --step--1 uppercase tracked-out stone/muted.
- 10. GRAIN ON DARK SECTIONS ONLY — add a ::after overlay on .section--navy: background-image: url("data:image/svg+xml,...feTurbulence baseFrequency='0.9' numOctaves='2'..."); opacity: 0.03-0.04; pointer-events: none; mix-blend-mode: overlay. Inline data-URI, no request, ~500 bytes. Never on bone/stone sections (kills the clean editorial read) and never animated.
- 11. RATION BREAK-THE-BOX — audit new pages so at most one grid-break moment appears per ~1.5 viewport heights (an offset Remotion loop crossing a section boundary, a pull-quote hanging into the gutter, one clipped headline). 2026 commentary validates broken-grid moments as differentiation precisely because they are exceptions to an otherwise disciplined grid; stacked, they read as the brutalist template they're reacting against.
- 12. MOTION-LOOP PARALLAX-LITE — give existing video.motion-loop containers a progress-linked drift via animation-timeline: view(): translateY from 24px to -24px across the viewport pass (±24px max — gentle, not parallax-hero). @supports-guarded, reduced-motion-gated, no JS. Reinforces the loops' presence without adding new media.
- 13. HOVER/FOCUS STATE PASS — every new card/link/button gets a defined hover AND :focus-visible state (cobalt→cobalt-2, translateY(-2px) + --shadow-2 on cards, 150-200ms var(--ease)); underline thickness transition on text links (text-decoration-thickness 1px→2px). 2026 sources flag unacknowledged states as the clearest cheap-template tell; this is the cheapest premium signal available.
- 14. REVEAL TIMING TUNE — standardize new reveals to the researched numbers: IO threshold 0.1 / rootMargin '0px 0px -12% 0px', opacity+translateY(16-20px) only (no scale, no blur filters), 450-600ms, var(--ease-out), stagger siblings 60-90ms, cap visible stagger chains at 5 items. Anything already on screen at load renders revealed (no reveal class above the fold).
- 15. PAGE-TOP ENTRANCE, NOT PRELOADER — no loading screens or curtain wipes (dated). Each page's above-the-fold gets one orchestrated entrance: eyebrow 0ms, data-split headline 80ms, supporting text 200ms, CTA 300ms, all within 700ms total — then the page is still. Combined with move #3, navigation feels continuous without a SPA.
- DO NOT: scroll-jack or hijack wheel delta anywhere; add horizontal-scroll sections on core pages; introduce a second typeface or a serif (Figtree-only discipline IS the brand); use blob shapes, first-gen glassmorphism, or 3D/WebGL/Spline heroes (800kB-2MB JS, CWV failure); animate type kinetically on body content; add cursor followers/custom cursors (agency-template tell by 2026); use generic AI imagery; let any marquee run without pause-on-hover/focus and a reduced-motion static fallback; hide content behind reveals for no-JS or reduced-motion users (content must be readable with JS off); stack multiple break-the-box moments in one viewport; add a preloader; exceed ~700ms for any single reveal or ~40s for a marquee loop.
