# Copy QA — 24 gates (run on every page before ship)

Voice note: CPC speaks as **"we"** (team) sitewide; "I" only in the About founder note, /ticket, and personal notes. Gate 21 below is adapted accordingly — the research version assumed solo voice.

1. **Negative parallelism** — regex `not just|not only|isn't just|more than just|It's not .*—it's|We don't .*\. We` → state the positive claim with a specific. Max 0.
2. **AI vocab** — delve, landscape, robust, seamless, elevate, tapestry, testament, pivotal, crucial, meticulous, foster, bolster, showcase, underscore, leverage, holistic, empower, unlock, streamline, actionable → plain word or cut. Max 0.
3. **Formulaic openers** — "In today's / In an era / When it comes to" or any sentence true of every business → open with a specific claim, question, price, or scene. Max 0.
4. **Summary endings** — "In summary / Overall / Ultimately / At the end of the day" or restating → end on the next step or a concrete detail. Pages end at the CTA. Max 0.
5. **Significance inflation** — "testament to / plays a vital role / underscores / reflects a commitment to" → show the evidence (the 8-client cap, stated plainly). Max 0.
6. **Rule-of-three stacking** — >1 triplet list per page, or two in one paragraph → cut to the one that matters or extend to an uneven 2 or 4.
7. **Vague attribution** — "experts / studies show / many businesses" unnamed → name the source, use lived experience, or cut. Max 0.
8. **Hedged non-claims** — "can help / may improve / is designed to" → commit, or state the honest condition ("This works if you answer your phone").
9. **Canned asides** — "It's important to note / Keep in mind" → delete the frame, keep the content.
10. **Em-dash density** — >1 per ~150 words or 2+ in a paragraph → periods, commas, parentheses.
11. **Uniform rhythm** — every sentence 15–25 words / same structure → add a short sentence (≤6 words). Every page needs a few sentences under 8 words.
12. **Copulative avoidance** — "serves as / functions as / boasts / offers" where is/has would do → is/has.
13. **Generic metaphors** — journey, navigate, roadmap-as-metaphor, landscape, next level → none, or one drawn from the client's actual world, earned.
14. **Over-parallel headings** — 3+ consecutive H2/H3s in identical grammatical form → break it; one plain statement or question ("What this costs", "Who this isn't for").
15. **Title Case + format soup** — Title Case headings, bold-label lists, emoji bullets, 3+ bullet lists per page → sentence case, half the lists become prose, zero emoji.
16. **Elegant variation** — 3+ synonyms for one referent → pick one. CPC default: "clients" for ours, "customers" for theirs.
17. **Participial tails** — ", ensuring X / helping you Y / allowing Z" → own sentence with evidence, or cut.
18. **Promotional adjective clusters** — 2+ of vibrant/comprehensive/innovative/cutting-edge/world-class per paragraph → one verifiable fact instead.
19. **"Whether X or Y" false range** — name the actual reader; each page addresses one pathway.
20. **Specificity floor** — every page carries at least two of: a real price, the 8-client cap, the 3-month minimum, an Indy-area place name, a named method step, a timeframe.
21. **Active team voice** — passive voice >10% of sentences → convert ("a plan is developed" → "we write the plan"). At least one stated opinion per page ("We think most small businesses buy ads too early."). "I" only on About founder note and /ticket.
22. **Texture** — zero contractions / no sentences starting with And, But, So / no fragments / no asides → add them. One admission per page is good ("This part is boring. Do it anyway.").
23. **Sameness across pages** — repeated opening constructions or identical CTA phrasing on 3+ pages → vary wording per audience, same destination.
24. **Read-aloud gate** — any sentence Carson couldn't say across a table at a coffee shop on Mass Ave → rewrite it as spoken, price included.

Also verify: title ≤60 chars, meta description 140–160, exactly one h1, FAQ schema mirrors visible text, no banned-by-brand words (funnel, synergy, game-changing, skyrocket, ROI-driven), money copy wit-free.
